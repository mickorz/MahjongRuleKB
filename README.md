# MahjongRuleKB

麻将规则结构化知识库：以杭州麻将为基础规则，通过差异化规则描述派生萧山、桐庐、绍兴等地方玩法，供 AI Agent 查询与游戏规则、结算逻辑生成使用。

## 概述

- **定位**：结构化规则知识库（规则/判定/时序/状态/算分/界面九类），而非普通文档存储。
- **基础规则**：杭州麻将好友房核心流程，作为所有地方玩法的派生基准。
- **派生方式**：地方玩法只描述「相对杭州麻将的差异」，由知识库组合出完整可验证的新玩法规则。
- **服务对象**：AI Agent 规则查询、PrdGameSkill 生成游戏 PRD、规则判定代码、结算逻辑与测试用例。
- **现有内容**：杭州麻将核心流程、萧山麻将好友房结构化规则、知识库建设方案。

## 快速开始

克隆仓库后直接阅读根目录规则文档：

- `【杭州麻将】核心流程杭州麻将好友房AI-11-19.md` —— 基础规则
- `【萧山麻将】好友房规则-结构化.md` —— 差异化派生示例（九类分类法）
- `项目需求.md` —— 知识库建设方案与规划
