# 快速开始

## 前提条件

- Git 2.30 及以上（克隆仓库）
- 任意 Markdown 阅读器（VS Code、Typora、Obsidian 或 GitHub 网页）
- 无需安装任何运行时依赖（纯文档知识库）

## 安装

```bash
git clone https://github.com/mickorz/MahjongRuleKB.git
cd MahjongRuleKB
```

## 验证

克隆完成后，仓库根目录应能看到：

- `【杭州麻将】核心流程杭州麻将好友房AI-11-19.md`（基础规则）
- `【萧山麻将】好友房规则-结构化.md`（差异化派生示例）
- `项目需求.md`（知识库建设方案）

## 第一次运行

知识库的「第一次使用」就是按顺序阅读：

1. 先读 `项目需求.md`，理解知识库的定位（结构化规则库 + 差异化派生）。
2. 再读杭州麻将文档，掌握基础规则（判定、时序、算分、界面）。
3. 最后读萧山麻将文档，理解「只记差异」的结构化描述方法（九类分类法）。
