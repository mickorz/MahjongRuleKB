# 配置参考

## 配置字段

当前仓库为纯文档知识库，**暂无运行时配置项**。

规划中的结构化规则配置（对应地方玩法差异描述中的「规则/配置」类）包括：

| 字段 | 类型 | 默认值（杭州基准） | 说明 |
|------|------|-------------------|------|
| 底分 | 数值 | 1 | 单局计分基数 |
| 局数 | 数值 | 待定 | 一场牌局的局数上限 |
| 财神 | 玩法标记 | 有 | 是否启用财神（万能牌） |
| 封顶 | 数值 | 待定 | 单局得分上限 |

## 生效与验证

纯文档仓库不涉及配置生效；规则差异的「生效」体现为知识库组合派生出的完整玩法描述，验证方式见 `zh-CN/testing.md`。

## 升级

文档仓库直接 `git pull` 即可获取最新规则内容。

## 卸载

删除本地克隆目录即可，无残留进程或依赖。
