# 常见问题排查

## 安装问题

**克隆后中文文件名乱码**：Windows 下执行 `git config --global core.quotepath false` 后重新查看。

## 运行问题

**找不到某条规则的出处**：按九类分类法定位（规则/判定/时序 → 状态/计数/记录 → 算分/公式/查表/入账分配 → 界面），再回到杭州基础规则文档核对默认值。

**两个文档对同一规则描述不一致**：以杭州麻将基础规则文档为准；地方玩法文档只描述差异，若差异描述与基础规则冲突，说明基础规则已修订而差异未同步，按 `zh-CN/how-to-guides.md` 的「修改基础规则」流程处理。

## 仍无法解决

在 GitHub 仓库 issue 区提交问题，附上文档名与具体条目。
