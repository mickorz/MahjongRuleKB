# 操作指南

## 示例任务：新增一个地方玩法（如桐庐麻将）

**问题场景**：想为桐庐麻将建立结构化规则，作为新的派生玩法。

**步骤**：

1. 通读杭州麻将基础规则文档，列出桐庐玩法中所有与杭州不同的点。
2. 新建根目录文档，命名为 `【桐庐麻将】好友房规则-结构化.md`。
3. 按萧山文档的九类分类法组织内容：规则（配置/判定/时序）、状态（计数/记录）、算分（公式/查表/入账分配）、界面（静态/交互/动效）。
4. 只写差异项，不重复基础规则；完全一致的部分标注「同杭州麻将」。
5. 提交并在 README 概述中补充一行该玩法条目。

**预期结果**：知识库新增一个可独立派生完整玩法规则的差异描述文档。

## 示例任务：修改基础规则

**问题场景**：杭州麻将基础规则本身需要修订。

**步骤**：

1. 修改 `【杭州麻将】核心流程杭州麻将好友房AI-11-19.md` 中对应条目。
2. 全文检索其他地方玩法文档中引用该条目的差异描述，同步核对是否仍成立。
3. 在提交说明中注明影响范围。

**预期结果**：基础规则变更且所有派生文档与其保持一致。

## 示例任务：用 AI Agent 查询规则

**步骤**：将本仓库作为上下文提供给 Agent，先给基础规则文档，再给目标玩法差异文档，让其组合回答。

**预期结果**：Agent 输出完整、无冲突的目标玩法规则。
