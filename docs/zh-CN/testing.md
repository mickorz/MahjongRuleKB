# 安装与运行验收清单

## 概述

本仓库为文档知识库，验收对象是「文档结构与内容质量」而非运行时行为。

## 安装检查

- [ ] 克隆成功，无 LFS / 编码报错
- [ ] 根目录包含杭州麻将基础规则文档与萧山麻将差异文档
- [ ] `docs/` 与 `docs/zh-CN/` 同名同结构的 6 篇文档齐全

## 冒烟测试

- [ ] 任选一篇地方玩法文档，其九类分类与萧山文档结构一致
- [ ] 差异文档中无与杭州基础规则矛盾的条目
- [ ] 文档内引用的文件名真实存在（交叉引用有效）

## 最终清单

- [ ] 新增文档已放入正确位置（规则文档在根目录，过程文档在 dev-docs/）
- [ ] README 概述已同步新增的玩法条目
- [ ] 提交信息说明变更范围
