# 为什么离线快照里点击 tab 没反应

> 对象：`dev-examples/style-capture/bishuxiezuo/offline.html`（抓自 `https://bishuxiezuo.cn/console/console.html`）
>
> 现象：页面样式正常，但左侧「世界观 / 角色表 / 故事规划」点击无任何效果。
>
> 结论：**这不是抓漏了文件，而是这类"点击"本质上需要后端参与**，静态快照无法复制。下面分三层说明。

---

## 一、第一层原因：快照里没有 JavaScript

`offline.html` 生成时把全部 `<script>` 移除了 —— 不是疏忽，是必然：

| 如果不移除 | 会发生什么 |
| --- | --- |
| 保留 `<script src>` 指向原站 | 脚本会重新执行 React 启动流程，从后端拉数据；无登录态 → 报错或跳登录页 |
| 改指本地 `js/`（已抓 186 个） | 同样执行启动流程，`fetch` 打向线上 API，结果同上 |
| 保留 `<script>` 且屏蔽网络 | React 挂载失败，整个 DOM 被清空 → 页面空白 |

原始页面是**空壳 HTML + React 运行时渲染**：抓到的 38 KB HTML 是渲染结果，不是源模板。React 启动时会用自己的虚拟 DOM 覆盖它，所以"保留脚本 + 保留渲染结果"必然冲突。

## 二、第二层原因：点击事件绑在 React 根上，不是 DOM 上

实测（登录态下）：

```js
[...document.querySelectorAll('.pbi')].map(b => ({
  text: b.textContent,          // "世界观" / "角色表" / "故事规划"
  cls: b.className,             // "pbi on" / "pbi"
  onclick: b.onclick,           // null ← 没有内联处理器
}))
```

所有 tab 都是 `<span class="pbi">`，**没有 `onclick` 属性**，也没有 `href`。事件由 React 在 `#root` 上做事件委托，靠内部状态切换。

这带来两个后果：

1. 静态快照里这些 `<span>` 是纯文本，点它天然不会有任何行为；
2. 想靠"给它们补 onclick"实现切换也不行 —— **其它 tab 的内容根本没在 DOM 里**。

## 三、第三层原因：这三个 tab 不是"切换视图"，而是触发后端生成

这是最关键的一点。实测点击「角色表」后，页面进入：

```
3 / 6 · 角色表
正在编织全员信念生态……
1 / 6  ① 阵容骨架 全员批量 · 1 次调用
       ② 信念生态 全员批量 · 1 次调用
```

而点击后 DOM 里：

```
.pbi 数量 = 0     ← 原来的 tab 栏消失了
.cs-t 数量 = 6    ← 换成了步骤条
```

也就是说：这三个 tab 属于向导流程（立意 → 世界观 → 角色表 → 故事规划 → 卷大纲 → 世界就位）中的**步骤导航**，点击会：

1. 切换路由/屏幕（React 条件渲染，旧屏幕 DOM 被卸载）
2. **向服务端发起生成请求**（`全员批量 · 1 次调用`）
3. 用 SSE/流式响应持续更新 DOM

所以离线页面无论怎么补 JS，都无法得到这个行为 —— 它依赖服务端计算，而且会消耗账号额度。

### 需要说明的操作风险

我在分析过程中点击了「角色表」以观察 DOM 变化，**这触发了一次真实的生成请求**（页面显示"正在编织全员信念生态"）。如果该操作产生了扣费或占用了额度，请检查账号；后续我不再对线上页面做任何点击。

## 四、如果一定要"能点"，有三条路，成本递增

| 方案 | 做法 | 能到什么程度 | 成本 |
| --- | --- | --- | --- |
| A. 多状态静态快照 | 逐步骤截图式抓 DOM，本地用 JS 切换 | tab/步骤能切换，内容是**抓取那一刻的冻结副本** | 中（每状态一次抓取；且抓取过程会触发后端） |
| B. 录制回放 | 抓 CDP 网络，把响应录成 JSON；本地起 mock 服务 + Service Worker 拦截 `fetch`，保留原 JS | 真实交互（含流式），但只覆盖录过的请求 | 高（要处理鉴权、SSE、动态 ID） |
| C. 完整镜像 | 上述 + 本地假后端（登录态、生成接口都打桩） | 近似真机 | 很高，且需持续跟随上游改动 |

**当前推荐的用途**：把 `offline.html` 当作**视觉参考**（配色、字体、间距、卡片结构），不要期待交互。需要看交互就用在线站点。

## 五、当前抓取产物各自能干什么

| 文件 | 能干什么 | 不能干什么 |
| --- | --- | --- |
| `offline.html` | 完全离线看样式与文案（CSS 本地化） | 任何点击 |
| `rendered.html` | 读渲染后的完整 DOM 结构 | 点击（无 JS） |
| `all.css` / `css/` | 搜索任意选择器、比对样式实现 | — |
| `js/`（186 个） | 阅读实现：React 组件、页面模块、事件绑定、请求封装 | 直接离线运行 |
| `design-tokens.css` | 取设计变量（ink/gold/sage、字体栈、缓动） | — |

后续若要 A 方案，我可以做一个**只读状态采集器**：只在页面已生成完毕、不触发新请求的前提下抓取多个已存在屏幕；任何会写数据的点击都不执行。
