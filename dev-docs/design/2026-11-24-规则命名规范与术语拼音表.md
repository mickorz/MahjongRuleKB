# 规则命名规范与术语拼音表

> 日期：2026-11-24
> 起因：`compiled/` 与规则源里文件名、目录名中英文混用（`hj-r-caishen` 拼音 / `hj-r-priority` 英文 / 目录全英文），难以检索与交接。
> 结论：文件名与目录名统一用中文拼音；ID 结构不变。本文是迁移记录，也是后续新增规则时的取名依据。

## 命名规范

1. **ID 结构**：`<规则集前缀>-<类型字母>-<拼音CODE>`，例如 `HJ-R-ZHUANGJIA-02`。
2. **CODE 段**：中文语义的拼音，全大写；多词用连字符分词（`CHI-JINSHOU`、`PIAOCAI-XIANZHI`），不写成 `CHIJINSHOU`。
3. **系列卡**：同一类型下成系列的卡改拼音后保留数字后缀（`BANK-01..04` → `ZHUANGJIA-01..04`、`HU-01..04` → `HUPAI-01..04`）。
4. **文件名**：等于 ID 的小写（`hj-r-zhuangjia-02.md`），一个卡一个文件。
5. **目录**：按类型字母落到拼音目录，见下表；目录名与 `type` 值（schema 枚举，保持英文）是两回事，别混。
6. **拼音写法**：不带声调、不缩写；专有名词按麻将通行读音（`zimo` 自摸、`qianggang` 抢杠、`dianpao` 点炮、`huangzhuang` 黄庄）。
