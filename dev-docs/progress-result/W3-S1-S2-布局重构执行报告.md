## 二、浏览器实测数据

```json
{ "head": {"h":38}, "body": {"h":858}, "nav": {"w":240}, "main": {"w":1486}, "aside": {"w":320},
  "foot": {"h":32, "top":895}, "splitters": 2,
  "status": {"segments":"111","edits":"0","unreviewed":"8 / 8","checks":"warning"},
  "bodyScroll": "927/927" }
```

`bodyScroll` 等于视口高度，证明外壳不再滚动，滚动交给三栏。

拖拽实测：左栏 240 → 360，`localStorage` 记录 `{"nav":360,"aside":320}`；双击回到 240。

## 三、修掉的自身问题

1. **`setPointerCapture` 对无效 pointerId 抛错会中断整次拖拽** —— 合成事件复现了这条，已用 try/catch 包裹。真实鼠标不会触发，但测试与无指针环境会。
2. **变体文档缺机器检查结论** —— `run-w2` 只写差异告警，不写 `quality-report.json`；工作台读不到就显示「—」。已补：继承一致性失败记 `failed`，差异告警记 `warning`。
3. 测试断言更新：首页 HTML 断言从 `<nav>`/`<aside>` 改为布局标记（`data-layout`、`splitter`、状态栏 `aria-label`）。
