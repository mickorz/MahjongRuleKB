## 3. 过程中修掉的问题

| # | 问题 | 修法 |
|---|---|---|
1 | `git worktree add ../../...` 相对路径按**参考仓库根**解析，跑到 `E:/dev-examples` | 一律用绝对路径 |
2 | Windows 上 Vite `resolve.alias` 把 `E:\...` 当相对路径拼成 `./E:\...` | 改 `resolveId` 插件 + `replaceAll("\\", "/")` |
3 | worktree 检出为 CRLF，patch 锚点（LF 写法）匹配不上 | patch 前归一为 LF、写回时还原 |
4 | 入口文件放在 `vendor/` 下，向上找不到 `node_modules`（react 解析失败） | 构建时把入口暂存到 worktree 内 `.xc-chat/`，build 后清理 |
5 | 模板字符串里写正则，反斜杠被吃掉导致生成的 vite 配置语法错误 | `resolveId` 里改用 `endsWith` 判断，不用正则 |
6 | `mountChat` 重复调用在同一宿主上建多个 React root，导致后续 `applyTurns` 落到失效 root | `WeakMap<HTMLElement, ChatHandle>` 保证一宿主一 root，重复 mount 等于 applyTurns |
7 | 轻量 markdown 在 `for..of` 里 `splice` 输入数组 → 死循环，整棵 React 树被卸载（页面空白、无报错） | 改为下标推进、不改输入；补表格支持 |
8 | 旧会话数据里 `tools` 是字符串数组（新代码按对象读） | payload 兼容两种形态 |

## 4. 已知差距（如实记录，非阻塞）

1. turn 头部显示「工作了 0 秒」：参考项目按 turn 级 `createdAt/completedAt` 算时长，我们只提供 item 级 `timestamp`
2. 工具摘要显示英文工具名（`get_rule`）：它的中文映射表只覆盖自己的工具；我们的六个只读工具需要注入 label 映射
3. Composer 仍是工作台自己的（未替换为参考项目输入框）
4. 聊天面板是深色主题（参考项目令牌），嵌在纸色工作台里形成两套视觉；统一需要覆盖 `:host` 令牌
5. `server/chat-widget/` 与 `vendor/xc-chat/fork/` 不入库：新克隆需先跑 `node vendor/xc-chat/build.mjs`，否则自动回退内置渲染
