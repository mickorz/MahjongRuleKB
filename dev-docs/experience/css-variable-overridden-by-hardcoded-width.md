# CSS 变量被硬编码覆盖：中间栏宽度「自定义失效」

## 问题现象

工作台中间栏的正文列本来由 `--doc-w` 控制宽度，可以在 `:root` 改一个值就整体缩放。
某次「对齐参考站」的改动之后：

- 宽屏（2048px）下正文列固定 1200px 居中，两侧各留 300px 空白
- 拖动左栏分隔条，正文列宽度**不再变化**
- 用户反馈：「这个中间栏之前会自定义宽度，好像被覆盖了」

## 排查过程

1. `grep -n "doc-col\|--doc" server/viewer.ts` → `--doc-w` 变量已经**不存在**了
2. `git log -p -S "doc-col" -- server/viewer.ts` 看到两处历史：
   - `4685e1f`（S1）`#doc-body { max-width: 72ch }` —— 最初的阅读宽度约束
   - `fc9f6f6`（两栏改造）`#doc-body` 的 `72ch` 换成 `.doc-col { max-width: 680px }`
3. 当前代码是 `.doc-col { max-width: 1200px }` —— 写死的一个数字，变量没了

## 根因

对齐参考站 `.cr-vol-doc { max-width:1200px }` 时，我把「参考值」直接**写成字面量**替换了原来由变量驱动的 `max-width`：

```diff
- #doc-body { max-width: 72ch; margin: 0 auto; }
+ .doc-col { max-width: 1200px; margin: 0 auto; }
```

一次替换做了两件事：改了**默认值**（680 → 1200），又删掉了**唯一的调参入口**（变量）。
默认值本身不是错，错在把「一个可调的值」降级成「一个写死的值」——之后任何调整都要改源码、改样式、重发版。

## 解决方案

保留变量，只改默认值：

```css
:root {
  /* 中间栏阅读宽度：正文列的 max-width，改这一个值即可调整整栏宽窄 */
  --doc-w: 1200px;
}
.doc-col {
  max-width: var(--doc-w);
  margin: 0 auto;
  width: 100%;
  padding: 30px 40px 56px;
}
```

验证（浏览器里直接改变量，不看截图）：

```
--doc-w: 680px  → 正文列 680，卡片 600
--doc-w: 820px  → 正文列 820
--doc-w: 1003px → 正文列 1003
--doc-w: 1200px → 正文列 1200，规则卡 1120
```

这同时暴露了另一件事：**680 太窄、1200 才接近参考站**。变量在，调值就是一行；
写死的话，用户只能来问「为什么改了没用」。

## 同类问题（同一失败模式，已经踩过三次）

「把某一段整体替换掉」时，锚点或作用范围过大，顺手删掉了不相干的东西：

| 事故 | 表现 | 根因 |
|---|---|---|
| 本文 | 宽度不再可调 | 变量被字面量替换 |
| `f1f753f` 前后 | gallery 页面**组件样式全丢**（卡片没圆角、徽章没底色） | 替换 `<style>` 时命中 `<style>${baseStyles()}</style>`，把共享组件样式整段换成了页面样式 |
| 同期 | 页面白屏、所有函数 undefined | 模板里写 `\${baseStyles()}`（转义），共享样式整段没输出，所有 `var(--*)` 失效 |
| `730752c` | 底栏「段落」显示 `—`、编辑后底部工具条不出现 | 按函数边界切代码时把相邻的 `updateStatus` 与整个「编辑草稿」段一起删了 |

共同点：**用「从 A 到 B 全删」的方式改一个局部**，而 A/B 不是可靠边界。

## 预防 / 注意事项

1. **可调的值必须留在变量里**。改默认值可以，删变量不行；`var(--x)` 是产品可维护性的一部分，不是装饰。
2. **替换样式块前先数边界**：`grep -c "<style>"`，确认要替换的是第几段；替换后立刻 `curl` 一遍页面，检查关键的 `var(--*)` 是否还有值（`color-scheme`、`--gold-deep` 这类哨兵）。
3. **在模板字符串里写 `\${...}` 是错的**。它会让插值失效；模板里出现 `\${` 就应当视为 bug。
4. **切代码块前先列出函数清单**：`grep -n "^function\|^async function" file`，确认删除范围两端都是完整函数边界，删完跑一次 typecheck + 冒烟。
5. **改完用 DOM 计算值验证，不用截图猜**：
   ```js
   getComputedStyle(document.querySelector('.doc-col')).maxWidth
   ```
6. 每次改版式后至少核对一次「用户会不会想知道怎么调」——如果答案是会，就把它做成变量并写注释。
