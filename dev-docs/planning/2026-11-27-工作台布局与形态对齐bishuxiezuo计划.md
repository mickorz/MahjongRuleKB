# 计划：Rule Studio 工作台「布局与形态」对齐 bishuxiezuo 控制台

> 日期：2026-11-27
>
> 范围：**只搬布局与视觉形态**（骨架、间距、配色、字体、组件外观），不搬业务逻辑、不搬 React 技术栈、不改后端接口。
>
> 参考对象：`https://bishuxiezuo.cn/console/console.html`（抓取产物见 `dev-examples/style-capture/bishuxiezuo/`）
>
> 现状：Rule Studio 工作台是深色墨蓝三栏（`server/viewer.ts`），功能已通（编辑草稿、预览、应用、审查、来源面板、可拖拽分栏、底部状态栏）

---

## 一、目标

| 目标 | 判定方式 |
| --- | --- |
| 视觉语言换成参考站的「暖纸 + 墨字 + 金点」 | 截图对比与令牌一致 |
| 骨架换成参考站的「顶栏步骤 + 左栏卡片列表 + 中栏字段卡片 + 底部操作条」 | 结构与尺寸表一致 |
| 现有功能全部保留 | 522 条测试不回归；编辑/应用/审查链路手工复测 |
| 不引入构建工具 | 仍是 `server/viewer.ts` 单文件产出 HTML |

```
│ ● 已完成项 2   │  ├────────────────────────────────────┤  │

│               │  │ 关系图 / 维度卡                     │  │
│               │  └────────────────────────────────────┘  │
├───────────────┴──────────────────────────────────────────┤
│ 上一步 ····· 第 2/3 段 ····· 通过，下一步                  │  底部操作条
└──────────────────────────────────────────────────────────┘
```

要点：

1. **顶栏承担导航与进度**（步骤条 + 胶囊状态），不是放工具的
2. **左栏是列表**，每项带状态圆点与选中描边，不是纯文本目录
3. **中栏是卡片流**，字段采用「左标签 / 右值」两列，长文用 serif
4. **底部是操作条**（上一步 / 分页 / 下一步），不是状态栏
5. 浮层（修订记录）锚定在触发按钮下方 8px，宽 348px，箭头指向触发点

## 五、验收方法

| 项 | 方法 |
| --- | --- |
| 视觉一致 | 截图 + `getComputedStyle` 断言关键值（背景 `#FEFCF8`、正文 `--ink`、金色 `oklch(0.70 0.125 70)`、卡片圆角 8px、边框 `rgba(34,29,22,.10)`） |
| 结构一致 | 断言存在：顶栏步骤条、左栏列表项 ≥ 8、中栏字段卡 ≥ 4、底栏操作条 |
| 功能不回归 | `npm test` 522 通过；手工走「改字 → 预览 → 应用 → 版本 +1」「标记已审 → 状态变化」 |
| 性能 | 首屏无外部依赖（仅有字体 CDN 可选）；DOM 节点数不显著增加 |

## 六、风险与回滚

| 风险 | 应对 |
| --- | --- |
| 纸色 + 低对比导致弱化文字读不清（参考站 `--ink-3` 在纸底对比约 3.1:1） | 正文不用 `--ink-3`，仅用于标签；必要时提到 `--ink-2` |
| 顶栏塞入步骤条后拥挤 | 步骤条只显示圆点 + 当前章节名，完整名称放 tooltip |
| 编辑态与卡片化冲突（contenteditable 在卡片内） | 编辑态仅高亮描边，不改变卡片布局 |
| 与现有 `tabbed.html` 快照样式混淆 | 工作台与快照在不同端口/路径，互不影响 |
| 回滚 | 全部改动在 `server/viewer.ts` 单文件，`git revert` 一个提交即可 |

## 七、明确不做

- 不引入 React / Tailwind / TipTap（参考站是 AGPL，代码不复制；只借鉴形态）
