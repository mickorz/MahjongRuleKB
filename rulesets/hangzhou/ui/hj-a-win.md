# 胡牌与黄庄结算演出

- **起播**：服务端确认胡牌（自摸 / 点炮 / 抢杠）或黄庄。
- **位置**：桌面中央字样；番型字效在胡牌者方位；「点炮」在放铳者方位；飘分在各玩家座位内侧。
- **画面**：
  - 胡牌：橙金色「对局结束」。番型字效颜色随番型变化（金色「财飘」、绿色「平胡」等）。点炮和抢杠在放铳者方位显示「点炮」。胡牌张单独摆在赢家手牌尾端，带浅绿描边和来源标记（本家手掌、上家←、对家↑、下家→）。十风专属字效。
  - 黄庄：橙色「黄庄」。跳过飘分。
  - 飘分：正分金黄色纯数字（如 96），负分浅蓝灰色带减号（如 −32）。只在本局得分非 0 的玩家座位显示。
- **顺序**：亮出四家手牌 + 显示「对局结束」→ 播番型字效 → 字效退场后刷新累计积分、显示飘分 → 飘分淡出 → 小结算。
- **结束**：飘分淡出后短暂保留终局牌桌。
- **播完进入**：小结算面板。胡牌局按本端本局净得分切换主题（正分和 0 分金色「恭喜获胜」，负分蓝色「遗憾失败」）。黄庄统一蓝色「黄庄」。
