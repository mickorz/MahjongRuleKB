# 吃碰杠胡操作按钮

- **触发**：弃牌触发响应 / 本人行牌阶段有可执行操作。
- **控件**：本家手牌右上方按钮。弃牌响应从左到右【吃】【碰】【杠】【胡】【过】，蓝色【过】固定最右。本人行牌时【自摸】【过】或【杠】【过】。
- **允许**：
  - **碰**：显示【碰】【过】。两张可碰牌保持亮度，其余压暗。同次可胡时整手正常亮度。
  - **吃（单组）**：点【吃】直接提交。
  - **吃（多组）**：点【吃】展开可选顺子面板，每组三张正面牌，右侧【取消】。点【取消】放弃本家对这张弃牌的全部可选操作（含【胡】）。
  - **杠（单组）**：点【杠】直接提交。
  - **杠（多组）**：点【杠】横排显示候选牌（每组建 1 张正面牌），暗杠与加杠混排按花色点数升序，右侧【取消】。
  - **自摸**：只有本家看到【自摸】【过】。左侧显示可胡牌和预览倍数。预览 = 番型倍数 × 单笔庄闲倍率，自摸取三笔中最高一笔。
  - **吃胡 / 抢杠胡**：【胡】【过】，左侧卡片显示胡牌张和预览倍数。
- **禁止**：倒计时归零后按钮仍可点击，系统继续等待手动操作。
- **同次其余操作**：
  - 低优先级先提交时进入等待，更高优先级成立则取消；更高优先级都放弃则裁决低优先级请求。
  - 点共用【过】放弃同一事件下本家的全部待响应操作。
  - 放弃杠后本次操作机会内不再显示【杠】。
- **反馈文案**：碰成立播金色「碰」字；吃成立播「吃」字；杠成立播「杠」字；胡牌后显示「对局结束」、番型字效、「点炮」字样。

**手牌亮度规则**：碰/直杠时参与牌保持亮度其余压暗；可胡时整手正常亮度；暗杠和加杠按本次新进牌能否成杠判定——新摸牌能组成杠时参与牌亮其余压暗，可杠组仅由原有牌组成时手牌保持当前亮度。
