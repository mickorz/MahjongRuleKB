# 三摊落地提示

- **起播**：第 3 个有效摊使承包关系成立时。飘财期间合法吃到上家因摸打限制被迫打出的牌也正常计摊，达到第 3 摊立即播放，不延后。
- **位置**：四个客户端都在桌面中央、方位盘下方。
- **画面**：金色书法字「三摊落地」，字样底部带蓝色横向光效。
- **顺序**：以较大尺寸入场，迅速缩小到常态尺寸，短暂停留后在原位淡出。可以与吃牌者座位的金色「吃」字同时播放。
- **结束**：短暂停留后淡出。
- **播完进入**：提示播放期间获权玩家可以继续提牌、出牌，不阻塞行牌。小结算的「三摊承包」「反承包」标识按本局实际赔付结果显示。
