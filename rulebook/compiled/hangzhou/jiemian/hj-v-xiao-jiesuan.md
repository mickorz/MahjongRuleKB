# 小结算界面

- **出现条件**：胡牌局在飘分退出后；黄庄局在黄庄字样退场后。
- **位置**：覆盖在终局牌桌上，底层桌面透过暗色遮罩仍可见。
- **文案格式**：
  - **标题**：顶部居中。胡牌局按本端本局得分：≥ 0 金色「恭喜获胜」（本家行橙金高亮），< 0 蓝色「遗憾失败」（本家行蓝色高亮）。黄庄四端均蓝色「黄庄」。右侧显示房号和日期时间。
  - **四行**：按本家、下家、对家、上家从上到下固定排列。每行左侧座位标签 + 头像 + 昵称，中间手牌，右侧得分及标记。庄家所在行显示蓝色「庄」徽及「庄×3」。
  - **手牌摆布**：已吃碰杠的牌组放行首，杠的第 4 张垒在上方，暗杠顶牌正面。其余手牌按实际组合分组。十风赢家行以字牌序列替代手牌，上方显示「十风」。
  - **得分**：正分金黄色带加号「+8」，0 分金色「0」，负分浅蓝灰色带减号「−8」。
  - **承包标识**：赢家牌组上方黄色「承包」/「反承包」。赔付者得分右侧蓝底「三摊承包」/「反承包」。链式承包时赢家行同时显示两者。
  - **番型文字**：赢家牌组上方黄色，仅番型名及复合次数。复合番型次数写在括号内，如「杠爆（三连杠）」「杠飘（二连杠）」。
  - **胡牌方式**：赢家行最右侧金色「自摸」/「点炮胡」/「抢杠胡」。放铳者行蓝色「点炮」。
  - **胡牌标识**：胡入牌在其所属组合内显示，牌面右下叠绿色「胡」字。
  - **财神牌**：左下角单独展示本小局财神正面牌，左侧红底竖排「财神牌」。
  - **主按钮**：底部中央绿色。非末局【继续游戏】，末局【返回大厅】。
- **不出现**：本期无「剩余牌」「底栏辅助入口」功能。
- **保持到**：点击主按钮离开。末局【返回大厅】仅本端离房，其他玩家可留在自己的小结算页，全部离开后服务端回收房间。
