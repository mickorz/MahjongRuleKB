# 对局开始动画

- **起播**：仅在开房后的首次开局。房主点击【开始游戏】并开局成功后，四端直接播放。常驻玩家信息区开始隐藏记为 T=0。
- **位置**：单个客户端游戏可视区。上/左/右/下四色块（青蓝/蓝/蓝/金黄），介绍卡锚点依次 (50%,15%)、(17%,50%)、(83%,50%)、(50%,85%)。中央字样横排居中，宽约画面宽 20%。
- **画面**：金白色粗斜字「对局开始」配橙金外发光，背后半透明金色横向光带。四张绑定座位的玩家介绍卡（头像、显示分、昵称）。
- **顺序**：
  - T=0～130ms：隐藏常驻信息区。约 35ms 四色块从屏幕外侧滑入。约 65ms 中央字样淡入。
  - T+130～570ms：介绍卡从画面外进入滑到锚点。字样显亮时中心闪蓝白亮光、左右扫光、青白圆环扩张、光粒闪现。约 230ms 起光效逐步变淡。
  - T+570～700ms：介绍卡淡出，色块退回。约 670ms 骰子开始滚动。约 700ms 常驻信息区按局内布局恢复。
  - T+700～865ms：中央字样与光带淡出，与摇骰短暂重叠。约 865ms 结束。
- **结束**：约 865ms 字样和光带完全消失。桌面、常驻信息区、正在播放的摇骰继续显示。
- **播完进入**：摇骰、定财神、发牌。
