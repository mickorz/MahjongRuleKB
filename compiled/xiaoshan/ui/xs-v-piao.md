# 受限牌的压暗

- **挂**：`XS-R-PIAO`
- **差异**：新增
- **出现条件**：本人仍受至少一名发起者限制
- **位置**：本人手牌原位
- **文案格式**：无文字。当前可打的那一张保持可辨认。其余手牌原位压暗
- **不出现**：不再受任何发起者限制时
- **保持到**：限制解除。可提起的范围见 `XS-I-PIAO`
