# 番型

- **差异**：修改
- **杭麻**：平胡 1 倍。七对 2／4／8／16，清七对 4／8／16／32。无大对子、大吊车、清一色、乱风、正风、天胡、地胡这些番型行
- **取档键**：本次胡牌方式下、同一套合法拆法里成立的番型
- **表**：

| 番型 | 差异 | 倍数 | 成立 |
| --- | --- | --- | --- |
| 平胡 | 沿用 | 1 | 杭麻平胡 |
| 大对子 | 新增 | 2 | 同一拆法有四组刻子或杠，加一组对子。已碰刻、直杠、补杠、暗杠各计一组。杠必须是已经成立的实际牌组，财神不补成杠。财神可按杭麻补刻或补对。有已吃出的顺子则不成立 |
| 大吊车 | 新增 | 2 | 胡入前四组吃、碰或杠都已成立，手牌只剩一张未入组的牌，胡入牌与它成对。暗杠计一组。杠后补牌可以是胡入牌。手中临时拆出的面子不计 |
| 清一色 | 新增 | 8 | 同一拆法中，胡入牌、对子和全部牌组（含暗杠）取牌面后，都是万、筒、条中的同一花色。财神按该拆法替代后的牌面。有字牌或第二种数牌，该拆法不成立 |
| 乱风 | 新增 | 64 | 仅自摸。没有已完成的吃、碰、杠。含胡入牌共 14 张都能视为字牌。字牌为东南西北中发白。财神可代字牌。不要求拆成面子。尚未开杠的四张同牌仍是四张手牌 |
| 正风 | 新增 | 128 | 仅自摸。没有已完成的吃、碰、杠。14 张拆成四组字牌刻子加一组字牌对子。财神可代字牌 |
| 天胡 | 新增 | 128 | 仅自摸。庄家发牌完成后，起手 14 张按本表已可自摸，且在首张弃牌前用这手牌直接自摸。先开杠再用补牌自摸，改走杠后番型 |
| 地胡 | 新增 | 128 | 仅自摸。闲家第一次常规摸牌后已可自摸，且用这次摸入的牌直接自摸。首摸前桌上已有吃、碰、杠仍可成立。常规摸牌与杠后补牌分开记录。用补牌自摸改走杠后番型 |
| 十风 | 原文未单列 | 原文未定 | 仅自摸。本文只规定它在 `XS-K-STACK` 里的位置 |
| 七对 | 修改 | 4 / 8 / 16 / 64 | 普通、豪华、双豪华、三豪华。成立、财神、豪华组数沿用杭麻 |
| 清七对 | 修改 | 8 / 16 / 32 / 128 | 同上四档。杭麻原为 4 / 8 / 16 / 32 |

- **表里没有的档**：十风的倍数。杭麻已有、本表未改倍数的番型沿用杭麻
- **多档同时**：见 `XS-K-STACK`。七客、七飘、七双飘的组合关系沿用杭麻，基础倍数改用本表
